# Expense Tracker
A self-built full-stack web application to manage and 
analyse daily financial transactions.

## About
Independently developed end-to-end — from planning and 
database design to Power BI dashboard and documentation.

## Tech Stack
- Python (Flask)
- MySQL
- HTML, CSS, JavaScript
- Power BI
- REST APIs

## Features
- Add and categorise daily expenses
- Monthly summaries and budget comparisons
- Savings pattern analysis using SQL queries
- Power BI dashboard for data visualisation
- Improved tracking efficiency by ~30%
- 
## How to Run
1. Clone this repository
2. Install dependencies: pip install -r requirements.txt
3. Run the app: python app.py
4. Open your browser and go to: http://127.0.0.1:5000
